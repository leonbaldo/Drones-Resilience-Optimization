# Assumptions and values to check or defend

Every number or modelling choice used by the resilience study (`resilience/` package, `resilience_study.ipynb`).
Tags match the comments in `resilience/config.py`.

**Status** says how solid each item is:
- **verified**: checked by a test or by the model itself;
- **inherited**: taken unchanged from the original model or earlier work; the source still needs citing;
- **calibrated**: chosen after seeing results; it must be reported as a calibration;
- **chosen**: a design choice made for this study; it needs a justification in the paper;
- **open**: still has to be checked.

Add a line here whenever a value changes, with the date and the reason.
